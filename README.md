# Cascade

Cascade is a browser-native Draw One Klondike solitaire game. Build the four foundations from Ace to King, arrange the tableau in alternating colors, and enjoy the celebratory card cascade when the last card reaches home.

## Development

```sh
npm ci
npm run dev
```

For a production build:

```sh
npm run build
npm run preview
```

Click or touch cards to drag them. Click the stock to turn one card, double-click a playable card to send it home, and use the bottom controls for a new game, the menu, and sound. The title and how-to menus also support Arrow keys or W/S, Enter/Space, and Escape.
